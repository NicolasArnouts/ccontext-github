# Hello World! 👋

Welcome to **ccontext-github**!

## What is ccontext-github?

ccontext-github is a powerful tool that generates context from GitHub repositories. It allows you to:

- Clone and analyze any public GitHub repository
- Generate comprehensive code context using AI
- Chat with AI about your codebase
- Export reports in multiple formats (Markdown, PDF)
- Visualize your project structure interactively

Simply provide a GitHub repository URL, and let AI help you understand the codebase better!
